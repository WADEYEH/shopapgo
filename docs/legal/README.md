## 政策草稿依据的决定

政策里的每个数字都来自已确认的决定，之后网站上线时，系统会自动比对政策页和结账规则是否一致（M11）：

| 内容 | 决定 |
|---|---|
| 只送 48 州和 DC，不收 AK、HI、领地、PO Box、军邮 | D4 |
| 运费每单 $7.99，标准配送，大多 3–5 个工作日 | D31、D12 |
| 付款后 1 小时内可以取消或改地址 | D23 |
| 送达 30 天内、未开封可退；改变心意由顾客付运费，原运费不退 | D13、D18 |
| 瑕疵、损坏、寄错：附照片、寄回，邮资我们付（自付的凭收据最多 $15），有追踪号就补寄或退款 | D27、D29、D30 |
| 已开封的退货不退款、不寄回 | D18 |
| 不直接换货 | D18 |
| 客服 2 个工作日内回复，联络方式是信箱和联络表单 | D27、D28 |
| 付款方式：信用卡、Apple Pay、Google Pay、Airwallex Pay、PayPal | D14、D21 |

## 需要你们补的资料（草稿里用 [方括号] 标示）

1. **销售主体的正式名称和地址**：卖家是哪一家公司（例如台湾公司还是其他地区的公司）。
2. **公司所在国家**：隐私权政策的「国际传输」一段要用。
3. **资料保存期间**：订单纪录保存几年（草稿写 7 年）、客服纪录保存几年（草稿写 2 年）。
4. **公司全年营收是否超过 $26,625,000**：决定加州隐私法适不适用（见 privacy-choices.md）。
5. **要不要尊重浏览器的「不追踪」讯号（GPC）**：建议要，成本很低。隐私权政策草稿已经照这个写；不采用的话要删掉那一行。

## 建议的审阅顺序

1. 先看 sales-tax.md 和 privacy-choices.md 的第 1 节结论，决定要不要找会计师和律师。
2. 补上第 3 节列的资料。
3. 看四份政策草稿，确认写法符合你们的实际做法。
4. 交给会计师和律师做最后确认。
