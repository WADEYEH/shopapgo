# 隐私选项分析（草稿）

| 项目 | 内容 |
|---|---|
| 日期 | 2026-10-06 |
| 状态 | 草稿，给你和同事过目。**不是法律意见**；上线前建议请熟悉美国隐私法的律师确认 |
| 对应 | 企划 O7、情境 E11、L3 |

---

## 1. 一句话结论

要不要做加州隐私法要求的「不出售或分享我的个人资料」选项，**取决于公司全年营收有没有超过 $26,625,000**。不管有没有超过，我都建议做两件成本很低的事：隐私权政策写清楚，以及尊重浏览器送出的「不要追踪」讯号（GPC）。**不需要放欧洲那种 cookie 同意横幅。**

---

## 2. 加州隐私法（CCPA）适不适用

只要符合下面**任一项**就适用，不管公司设在哪里：

| 门槛 | 我们的情况 |
|---|---|
| 公司全年总营收超过 $26,625,000（2025 年调整后的金额） | **不知道，要你确认**。看的是整个销售主体的营收，不只美国网站 |
| 每年处理 10 万名以上加州居民或家户的个人资料 | 以目前规模，远远未达 |
| 一半以上的营收来自出售或分享个人资料 | 不符合 |

---

## 3. 如果适用，要做的事

- 隐私权政策加上加州居民的专门说明。
- 每一页放一个「Your Privacy Choices」（不出售或分享我的个人资料）连结，按下后，这位顾客的资料就不再送给 Meta 做广告。用 Meta Pixel 和 Conversions API 追踪广告成效，在加州法律下算是「分享」。
- 尊重浏览器的 GPC 讯号，视为顾客已经选择退出。
- 隐私请求在 45 天内回复（已经是我们的规则，E11）。

---

## 4. 如果不适用，我仍然建议做的事

| 做法 | 理由 | 成本 |
|---|---|---|
| 隐私权政策写清楚，列出所有接收资料的服务 | Meta、Google 的使用条款本来就要求网站要有隐私说明 | 已在草稿里 |
| 尊重 GPC：浏览器送出 GPC 时，不载入 Meta Pixel，也不送 Conversions API | 法律适用与否不必冒险判断；之后营收成长到门槛也不用再改 | 很低，只影响少数使用者 |
| 隐私请求照 E11 的流程处理 | 已经是我们的规则 | 已在规格里 |

---

## 5. cookie 同意横幅

- 美国大多数州采「顾客可以选择退出」的做法，**不要求先取得同意**，所以不需要欧洲那种进站就跳出的同意横幅。
- 我们只卖美国，但欧洲访客还是可能进站。欧盟的规定要求追踪前先取得同意。如果想避免这个风险，有一个低成本的做法：用 Cloudflare 判断访客所在地，欧洲访客不载入 GA4 和 Meta Pixel。这一项建议请法务一起判断要不要做。

---

## 6. 其他州的隐私法

很多州也有类似的隐私法，门槛多半是「处理 10 万名以上该州居民的资料」，以目前规模大多未达到。少数州对非小型企业不设人数门槛，适不适用要看公司规模，请律师一起确认。

---

## 7. 要问律师的问题

1. 依公司全年营收，是否适用加州隐私法？其他州呢？
2. 用 Meta Pixel 与 Conversions API 做广告追踪，在我们的情况下需要哪些揭露或退出选项？
3. 欧洲访客是否需要另外处理（例如不载入追踪）？
4. 隐私权政策草稿（`privacy-policy.md`）有没有缺漏？
